# PDF 免費翻譯

網站：<https://yueguov1989.github.io/pdf-translator/>

## 翻譯流程

目前採用 **免費線上機器翻譯 + Qwen3-1.7B 本機語境校正**：

1. PDF 由瀏覽器本機解析，抽取英文文字。
2. Qwen3 在瀏覽器本機分批分析全文，建立主題、人物／機構指涉、專業概念與固定術語表。
3. 免費線上翻譯服務逐段產生初稿。預設先嘗試 Google 翻譯網頁端點；若端點失敗，會自動切換 MyMemory。
4. Qwen3 將全篇背景、術語表、前後段落及機器翻譯初稿合併考量，校正每段譯文。

## 翻譯引擎與費用

- 本機模型：`onnx-community/Qwen3-1.7B-ONNX`
- 執行方式：Transformers.js + WebGPU + `q4f16`，選用單一 ONNX 權重檔以避開外部 `.onnx_data` 權重掛載相容性問題
- 模型卡列出支援 100 多種語言及 32,768 token 上下文；實際可用上下文會受瀏覽器記憶體、提示長度和生成設定影響。
- Google 翻譯網頁端點不需要 API 金鑰，但它不是 Google 官方公開 API，沒有穩定性、配額或長期可用保證，可能限流或變更。
- MyMemory 是備援免費服務，免費使用額度有限；若大量翻譯，可能觸及每日限制。
- 本專案不要求 Google Cloud API 金鑰，也不要求使用者設定付費帳單；但第三方免費服務政策可能變動。

## 隱私

- 原始 PDF 在瀏覽器本機解析，不會上傳整份 PDF。
- Qwen3 的全文分析與譯文校正於本機瀏覽器執行。
- 為取得機器翻譯初稿，抽取出的英文文字段落會傳送至所選第三方翻譯服務（Google 或 MyMemory）。因此不能將本版本描述為完全離線或文字絕不上網。
- 載入模型時，瀏覽器會從模型託管平台下載模型檔案。

## 主要功能

- 讀取可選取文字的 PDF。
- 繁體中文／簡體中文切換。
- 全文主題與術語分析。
- 前後文輔助逐段翻譯及校正。
- 手動修改譯文。
- 匯出中英對照 TXT。

## 硬體與瀏覽器要求

- 建議使用支援 WebGPU 的新版 Chrome 或 Edge。
- 首次使用需要下載 Qwen3 模型檔案，之後是否快取取決於瀏覽器儲存空間與設定。
- 模型量化後仍需要較多記憶體和 GPU 資源。低記憶體設備可能無法載入或速度很慢。
- Windows 電腦若只有 4GB RAM，未必能穩定運行 1.7B 模型。
- Android／iOS 裝置的 WebGPU 支援因瀏覽器、系統版本和 GPU 而異，不能保證所有手機都能運行。

## 上下文能力與限制

Qwen3 會先分批分析長文，形成全篇背景筆記，再用背景、術語表及前後段落校正每段機器譯文。這比單純逐段獨立翻譯更有機會保持多義詞、代名詞和術語的一致性。

但這不代表模型能完整記住或正確理解每篇文章的所有細節。分批摘要可能遺漏細節，小型模型也可能錯誤判斷語義。法律、醫療、合約、學術或其他重要文件仍應人工核對。

## 尚未支援

- 掃描圖片版 PDF 的 OCR。
- 匯出 Word 或重新排版 PDF（目前只有雙語 TXT）。
- 跨裝置同步模型或翻譯內容。
