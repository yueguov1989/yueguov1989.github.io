翻譯流程：免費線上翻譯 + Qwen3-1.7B

Qwen3 先分析全文；免費翻譯服務產生初稿；Qwen3 再依全文背景、術語表及前後段落校正譯文。

不需要 API 金鑰或付款資料。Google 網頁端點不是官方公開 API；若失敗會自動改用 MyMemory。MyMemory 免費服務有每日使用限制。

模型已改用單一 ONNX 權重檔，避開先前外部權重檔案載入錯誤。檔案約 1.43GB；請先檢查 WebGPU、設備記憶體及 Hugging Face 連線。不需要填寫 API 金鑰。

翻譯前先由 Qwen3 整理文章背景與術語；每段再由免費翻譯服務產生初稿，最後交給 Qwen3 結合全文資料校正。這能改善語境一致性，但小型模型仍可能誤解複雜語義，重要內容請人工校對。
