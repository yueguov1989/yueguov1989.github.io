PDF 英漢翻譯器

在瀏覽器讀取 PDF，逐段翻譯並對照原文。第一版先支援可選取文字的 PDF。

1. 選擇 PDF

PDF 在瀏覽器本機解析，原始 PDF 檔案不會上傳；但英文段落會傳送至 Google Cloud Translation API 取得初稿，再由本機 Qwen3 依全文語境校正。掃描圖片版 PDF 暫未支援 OCR。

請先選擇一份 PDF 檔案。
頁數：—文字：—段落：—

2. 翻譯設定

翻譯流程：Google 翻譯 + Qwen3-1.7B

Qwen3 先分析全文；Google 翻譯產生初稿；Qwen3 再依全文背景、術語表及前後段落校正譯文。

金鑰只保留在目前頁面的記憶體中，不會寫入網站或瀏覽器儲存空間。建議在 Google Cloud 將金鑰限制為你的網站網址，並只允許 Cloud Translation API。啟用 API 通常需要設定帳單帳戶；每月前 500,000 個文字字元有免費額度，超出後可能收費。

首次使用需要下載約 1–2GB 的 Qwen3 模型檔案；之後瀏覽器可能會快取模型。請使用支援 WebGPU 的新版 Chrome 或 Edge。開始翻譯前，還需要填入 Google Cloud Translation API 金鑰。

翻譯前先由 Qwen3 整理文章背景與術語；每段再由 Google 翻譯，最後交給 Qwen3 結合全文資料校正。這能改善語境一致性，但小型模型仍可能誤解複雜語義，重要內容請人工校對。
